# Addepar Interview Prep — 33 Problems

Source list: [Interview Solver — Addepar tag](https://interviewsolver.com/interview-questions/addepar)

This vault organizes the 33 tagged problems by **algorithmic pattern** rather than by list order, because interviews test whether you can recognize the pattern, not whether you memorized a specific problem. Each pattern folder has a `00-index.md` primer explaining the technique in general, followed by full tutorial notes for each problem — problem statement, intuition, pattern recognition callout, step-by-step algorithm, a working Python solution, complexity analysis, edge cases, common mistakes, and links to related problems.

## How to Use This Vault

1. **First pass:** read a folder's `00-index.md` primer before touching any problem in it — it tells you what to look for.
2. **Second pass:** open a problem note, read *Problem Statement* and *Examples*, then stop and attempt it yourself before reading *Intuition & Approach*.
3. **Third pass:** compare your solution against *Solution (Python)*, then read *Common Mistakes* — these are usually the exact traps interviewers probe.
4. Update the `status` field in each note's frontmatter (`not-started` → `attempted` → `solved` → `mastered`) and log it in [[Study-Tracker]]. Obsidian's search (`status: solved`) or a Dataview query can then filter your progress.
5. Use the **Graph View** in Obsidian to see how patterns interconnect — problems that share a technique will cluster together via the `Related Problems` links.
