# Study Tracker

Update the checkbox and status as you work through problems. Mirror the same value into the note's frontmatter `status:` field (`not-started` / `attempted` / `solved` / `mastered`) so Obsidian search/Dataview queries stay in sync.

> [!info] Optional: Dataview query
> If you install the community **Dataview** plugin, replace the manual table below with:
> ```dataview
> TABLE pattern as "Pattern", leetcode_difficulty as "Difficulty", status as "Status"
> FROM "01-Arrays-and-Two-Pointers" OR "02-Strings" OR "03-Sliding-Window" OR "04-Linked-Lists" OR "05-Hashing-and-Design" OR "06-Heaps-and-Priority-Queue" OR "07-Stacks-and-Monotonic-Structures" OR "08-Trees-and-Recursion" OR "09-Graphs-and-BFS-DFS" OR "10-Backtracking" OR "11-Dynamic-Programming"
> SORT status ASC
